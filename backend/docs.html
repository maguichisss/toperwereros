Authentication

All endpoints except POST /api/auth/login require a JWT Bearer token in the Authorization header.

SettingValue
Token formatJWT (HS256)
Expiry24 hours (configurable via JWT_EXPIRE_MINUTES)
SecretJWT_SECRET env var (default: dev-secret-change-in-production)
HeaderAuthorization: Bearer <token>

Business Rules

Products

  • Product code must be globally unique (enforced on create and update).
  • name, code, and price are required. Price ≥ 0.
  • All referenced category_ids and color_ids must exist; count must match.
  • Image files are deleted from disk on product update (old URL) and delete.
  • Search uses case-insensitive ILIKE across 6 fields simultaneously.

Sales

  • At least one item required.
  • Each product must exist and have sufficient stock.
  • unit_price is captured from the product at sale time (not from the request).
  • Stock decrement and sale creation are wrapped in a SQLAlchemy savepoint (db.begin_nested()).
  • created_by tracks which user made the sale.

Layaways (Apartados)

  • Must provide exactly one of customer_id or inline customer object.
  • Deposit must be > 0 and must not exceed the total.
  • Each item locks in the current unit_price and decrements stock.
  • The initial deposit is recorded as the first LayawayPayment.
  • When a payment brings the balance to $0, the layaway is automatically completed and a Sale is created.
  • Cancellation restores all product stock.
  • Completion is idempotent — if sale_id is already set, it's a no-op.

Image Uploads

  • Two upload endpoints: POST /api/upload (products) and POST /api/auth/avatar (profiles).
  • Validation is by magic bytes, not Content-Type header.
  • Supported formats: JPEG (FF D8 FF), PNG (89 50 4E 47), WebP (52 49 46 46).
  • Max file size: 5 MB. Min: 8 bytes.
  • Filenames are random UUIDs to prevent collisions.

PDF Catalog

  • Only in-stock products (stock > 0).
  • 4-column card grid, 16 products per page.
  • Each card: cropped product image, name, price (blue), code (gray).
  • Weekly header: "Catalogo Toperwereros" with valid date range in Spanish.
  • Images are center-cropped to fill 44×48mm at 72 DPI, converted to JPEG 85%.
